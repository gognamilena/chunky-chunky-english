CHUNKY CHUNKY ENGLISH — версия 0.3 (локальный прототип)

ЗАПУСК:
1. Распакуйте ZIP целиком в одну папку.
2. Не перемещайте index.html отдельно от папки assets.
3. Откройте index.html в Chrome или Edge.

В этой версии есть:
- новая Welcome Page с оригинальным изображением Chunky;
- формы регистрации и входа;
- короткий демонстрационный входной тест;
- предварительный результат A1–C1;
- личный кабинет и несколько демонстрационных уроков;
- локальное сохранение одного профиля в браузере.

ВАЖНО:
Это локальный прототип. Регистрация хранится только в localStorage на данном устройстве и не является безопасной серверной авторизацией. Пароль в прототипе не защищён — не используйте настоящий пароль. Для публикации и реальных пользователей следующим этапом подключим GitHub, Vercel и Supabase, добавим серверную авторизацию и базу данных. Оценка уровня пока предварительная и не является официальным тестом CEFR.
